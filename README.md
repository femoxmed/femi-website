# Femi Meduoye Portfolio Website

A complete single-page Next.js portfolio website with Tailwind CSS, Framer Motion animations, and a vibrant luxury tech theme.

## Run locally

```bash
npm install
npm run dev
```

Open: `http://localhost:3000`

## Build for production

```bash
npm run build
npm run start
```
